# Baseline Excel

Baseline helps Excel users build better habits by tracking inefficient actions
and coaching one improvement at a time — directly inside Excel.

## Who this is for
- Interns
- New associates
- Excel-heavy professionals

## What it does
- Detects inefficient Excel usage
- Assigns one weekly “upgrade” (e.g. Alt+=)
- Reinforces behavior through repetition

## How to run
1. npm install
2. npm start
3. Excel opens automatically with the add-in loaded
